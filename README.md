# HR System Management

Laravel 12 Human Resource Management System

## Features

- Employee Management
- Attendance Tracking
- Dashboard Analytics
- Authentication System
- Account Settings
- Maintenance Page
- Dark/Light Mode

## Technologies

- Laravel 12
- PHP 8.2
- MySQL
- Blade
- Tailwind CSS
- JavaScript

## Installation

git clone https://github.com/rainmission123/HR-System-Management.git

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve# Laravel-12-HR-System-Management
