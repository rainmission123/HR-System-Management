## Features

- Employee Management
- Attendance Tracking
- Dashboard Analytics
- Authentication System
- Account Settings
- Maintenance Page
- Dark/Light Mode

## Technologies

- Laravel 12
- PHP 8.2
- MySQL
- Blade
- Tailwind CSS
- JavaScript

## Installation
```bash
git clone https://github.com/rainmission123/HR-System-Management.git

cd HR-System-Management

composer install

copy .env.example .env

php artisan key:generate

npm install

php artisan migrate

npm run dev

php artisan serve
```
